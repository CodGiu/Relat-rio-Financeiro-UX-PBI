# 📊 Desafio de Projeto - Relatório Financeiro com Foco em UX/UI

Este repositório contém a solução do desafio de projeto focado na **reestruturação de um relatório financeiro**, com ênfase total em **Experiência do Usuário (UX)**, **Design de Interface (UI)** e **Navegabilidade**.

---

## 🎯 Objetivo do Desafio

O objetivo principal consiste em reformular o relatório financeiro original, aprimorando a usabilidade e a clareza visual para facilitar a tomada de decisão. 

As modificações visam transformar dados brutos em uma narrativa visual intuitiva, considerando os seguintes pilares de design:

*   **📌 Posicionamento:** Organização estratégica dos elementos e KPIs para guiar o olhar do usuário na ordem de importância.
*   **🎨 Contraste:** Uso de cores adequadas para destacar dados críticos, chamadas de ação (CTAs) e hierarquia visual.
*   **📐 Proporção Áurea:** Distribuição harmônica dos espaços no dashboard.
*   **📊 Segmentação dos Dados:** Filtros e segmentadores claros para permitir análises personalizadas.

> *Nota: As diretrizes de design funcionam como guias. Em momentos específicos, a quebra de algumas regras traz criatividade, originalidade e pontos de destaque ao relatório.*

---

## 🛠️ Implementações Realizadas

Com base nos requisitos do desafio, foram executadas as seguintes melhorias:

1. **Botões e Menus de Navegação:**
   * Inclusão de botões de navegabilidade entre as páginas do relatório.
   * Criação de menus integrados em cada página para facilitar a alternância de visões.
2. **Estilização Interativa:**
   * Customização nos estados dos botões (*Ao passar o mouse / Hover* e *Ao clicar / Selected*) para fornecer feedback visual claro ao usuário.
3. **Harmonização da Segunda Página:**
   * Reestruturação completa da segunda página seguindo a mesma identidade e padrão UX adotados na página principal.
